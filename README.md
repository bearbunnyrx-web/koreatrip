# Korea Trip Together

A mobile-first React app for Dr. Cho and his girlfriend to manage their Korea trip.

Current v1 includes:
- Home dashboard
- Itinerary view
- Bookings view
- Simple spending view
- Sofitel Ambassador Seoul stay integrated

Built with:
- React
- Vite

Planned next:
- Real trip data sync from Google Sheets
- Better booking urgency logic
- Place ingestion from Instagram links/lists
- iPhone-friendly install/deployment flow
